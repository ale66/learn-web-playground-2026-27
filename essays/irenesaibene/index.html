CORPORATE COMMUNICATION: WEB COMMUNICATION

Welcome to the Web Communication course!

Where to find us

We are pleased to welcome all students to the Web Communication course, during which we will explore the fundamental principles of web communication and web development, gaining practical knowledge of HTML, CSS, and JavaScript.

The aim of this course is to learn how to build a webpage by learning how to use the languages that make it up:

  1. HTML
  2. CSS
  3. JavaScript

To give students a chance to get a clearer grasp of the course, we recommend visiting the course website and watching a short beginner tutorial on how to use programming languages.
